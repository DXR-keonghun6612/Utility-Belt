# Code Hierarchy & Architecture Rendering Tool (CHART)

프로젝트 정적 분석을 위한 다이어그램 자동화 도구

## 목표

코드의 다양한 목적을 구분하고, 데이터 흐름, 코드 객체 구조 등을 인식하여 다이어그램을 그리는 서비스

### 작업 상태

- [ ] Python 지원 리팩토링
  - [ ] (parsing) 각 파일 별 구조 정보 추출
  - [ ] (parsing) 디렉토리 내부 파일 구조 분석
  - [ ] (rendering) draw io 랜더링 구조 정리
