# Ubuntu 시스템 모니터링 매뉴얼

Utility Belt의 시스템 모니터링 모듈은 서버의 하드웨어 및 주요 리소스 상태를 빠르게 파악하고 내보낼 수 있는 기능을 제공합니다.

## 1. 개요

- **UI 스크립트**: `ui/ubuntu/proc_system_moniter.sh`
- **백엔드 로직**: `script/system/ubuntu/02_system_moniter.sh`
- **주요 기능**:
  - 주요 하드웨어 정보(CPU, RAM, Disk 등) 조회
  - 시스템 정보를 JSON 형식으로 내보내기

## 2. 사용 방법

메인 메뉴에서 **System Monitor**를 선택하여 진입합니다.

### A. 하드웨어 정보 조회 (View Hardware Info)

다음 항목들에 대한 상세 정보를 텍스트 박스로 보여줍니다. 스크롤하여 전체 내용을 확인할 수 있습니다.

- **CPU**: 모델명, 코어 수, 클럭 속도, 아키텍처.
- **Motherboard**: 제조사, 모델명, 시리얼 번호, BIOS 버전.
- **Memory (RAM)**: 총 용량, 사용량, 슬롯별 장착 정보(속도, 제조사).
- **GPU**: 그래픽 카드 모델 및 상세 정보.
- **Storage**: 장착된 디스크 목록, 용량, 파티션 상태, 파일시스템 사용량.

### B. JSON 내보내기 (Export to JSON)

수집된 모든 시스템 정보를 구조화된 `JSON` 파일로 저장합니다.
- **용도**: 자산 관리 시스템 연동, 히스토리 기록, 외부 보고서 작성 등.
- **저장 경로**: 기본값은 현재 디렉토리의 `system_info.json`이며, 파일 탐색기를 통해 변경할 수 있습니다.
