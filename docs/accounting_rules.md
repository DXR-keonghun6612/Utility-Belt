# 복식부기 규칙 및 핵심 로직 가이드

이 문서는 CACHE 프로젝트의 핵심 엔진인 복식부기(Double-entry bookkeeping) 시스템의 4대 요소와 거래의 8요소, 그리고 결합 규칙을 정의합니다.

## 1. 4대 핵심 요소 (The 4 Main Account Groups)
시스템 내의 모든 계정 과목은 아래 4가지 대분류 중 하나에 속해야 합니다. 수익과 비용은 자본의 변동을 설명하는 **손익(P&L)** 계정으로 통합 관리됩니다.

| 요소 | 영문 (Alias) | 정의 | 예시 |
| :--- | :--- | :--- | :--- |
| **자산** | `Assets` | 기업(개인)이 소유한 재화나 채권 등 미래에 경제적 효익을 가져다주는 것 | 현금, 보통예금, 보증금, 자동차, 주식 |
| **부채** | `Liabilities` | 미래에 갚아야 할 채무 | 신용카드 대금, 대출금, 미지급금 |
| **자본** | `Equity` | 자산에서 부채를 뺀 순수한 소유주의 몫 | 기초자본, 이익잉여금 |
| **손익** | `Income/Expense` | 일정 기간 동안의 경영 성과(수익-비용)를 나타내는 계정 | 급여(수익), 식비(비용), 이자수익, 월세 |

---

## 2. 거래의 8요소 (The 8 Rules of Journalizing)
모든 거래는 차변(왼쪽)과 대변(오른쪽)에 동시에 기록되며, 양쪽의 금액 합계는 항상 일치해야 합니다.

| 위치 | 구분 | 의미 | 예시 상황 |
| :--- | :--- | :--- | :--- |
| **차변 (Left)** | **1. 자산의 증가** | 내 재산이 늘어남 | 월급 입금, 적금 만기 수령 |
| (Debit) | **2. 부채의 감소** | 빚을 갚음 | 카드값 선결제, 대출 원금 상환 |
| | **3. 자본의 감소** | 순자산이 줄어듦 | (개인 가계부에서는 드묾) |
| | **4. 비용의 발생** | 돈을 씀 (손익 계정) | 점심 식사, 버스비 지출 |
| **대변 (Right)** | **5. 자산의 감소** | 내 재산이 줄어듦 | 현금 인출, 계좌 이체 |
| (Credit) | **6. 부채의 증가** | 빚이 생김 | 신용카드 결제, 지인에게 돈 빌림 |
| | **7. 자본의 증가** | 순자산이 늘어남 | 자본금 출자 |
| | **8. 수익의 발생** | 돈을 벎 (손익 계정) | 급여 발생, 예금 이자 발생 |

---

## 3. 주요 거래 결합 예시 (Transaction Patterns)

### Case A: 비용 지출 (자산 감소형)
*상황: 체크카드로 10,000원짜리 점심을 사 먹음.*
*   **(차변)** 손익(비용) 발생 (식비 10,000)
*   **(대변)** 자산의 감소 (보통예금 10,000)

### Case B: 비용 지출 (부채 증가형)
*상황: 신용카드로 10,000원짜리 점심을 사 먹음.*
*   **(차변)** 손익(비용) 발생 (식비 10,000)
*   **(대변)** 부채의 증가 (미지급금/카드대금 10,000)

### Case C: 수익 발생 (자산 증가형)
*상황: 월급 3,000,000원이 통장에 들어옴.*
*   **(차변)** 자산의 증가 (보통예금 3,000,000)
*   **(대변)** 손익(수익) 발생 (급여 3,000,000)
